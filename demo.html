데모 확인 방법

아래 버튼을 누르면 해당 역할로 바로 로그인됩니다. 데모 데이터는 각자의 휴대폰·PC 브라우저에만 저장되며 실제 결제·문자는 발생하지 않습니다.

1

공동 업무함 — 김정환 대표이사로 보기

  • 왼쪽 메뉴 🔔 공동 업무함에서 견적문의·업체 심사·나라장터 공고를 확인
  • 업무를 눌러 "내가 처리하기" → 담당자가 표시됩니다
김정환 대표이사로 보기
2

같은 업무를 김종연 사내이사로 보기

  • 1번에서 처리한 업무에 "김정환 대표이사 · 처리중"과 확인 표시(✔)가 함께 보입니다
  • 메모를 남기면 대표이사 화면에도 이력이 공유됩니다
김종연 사내이사로 보기
3

비회원 견적문의 체험

  • 성함·휴대폰 번호 입력 → 인증번호 받기 (데모에서는 인증번호가 화면에 표시)
  • 문의 접수 후 관리자 공동 업무함에 "비회원 견적문의 — 연락 필요"로 등록됩니다
비회원으로 견적문의 하기 비회원 문의 조회
4

나라장터 입찰 관리

  • 관리자 메뉴 📢 나라장터 입찰: 자동 수집된 공고(데모 예시), 지역제한 판별, 마감 D-day
  • 공고를 눌러 낙찰하한율을 입력하면 투찰가 산정표가 계산됩니다 (투찰은 나라장터에서 직접)
나라장터 입찰 화면 보기
5

고객 · 업체 화면

  • 고객: 받은 견적 비교 → 업체 정보 확인 → 선정 → 테스트 결제
  • 업체(와이드가드): 매칭된 요청 확인 → 견적 제출 → 고객 상담
고객으로 보기 업체(와이드가드)로 보기 회사 홈페이지
직접 로그인할 때 (비밀번호 모두 demo1234)
관리자: admin@demo.com (김정환 대표이사) · admin2@demo.com (김종연 사내이사)
고객: customer@demo.com · 업체: vendor@demo.com
